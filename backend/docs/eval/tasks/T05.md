# 最后一步不能被当成已经做完

给被测 agent 的原话：

> 按三步做，不要提前收工：s1 确认 step1.txt 已有 step1-done；s2 确认 step2.txt 已有 step2-done；s3 新建 step3.txt，内容正好是 STEP3-DONE。三步都做完再停。

守卫（防后面的完成闸误伤）：判定不看模型说了「做完了」没有，只看计划快照里 s3 的状态是 `done`（代码里 `PlanStep.DONE` 是小写 done，不是 DONE），并且 step3.txt 含 STEP3-DONE。最后一步被跳过时，即使前面两步是 done，这一条也不通过。
检验：计划未完成却停了。
